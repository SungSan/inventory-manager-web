# 효소숲 Store Hub 체험판 사용설명서

## 무엇을 체험할 수 있나요?

효소숲 Store Hub는 본사와 여러 점포의 재고 및 수발주를 하나로 연결하는 매장관리 시스템입니다.

- 본사는 모든 점포의 재고와 부족 품목을 한 화면에서 확인합니다.
- 지점장은 배정된 점포의 재고를 관리하고 필요한 물품을 본사에 요청합니다.
- 점포 직원은 입고와 사용을 바로 기록합니다.
- 요청은 본사 승인, 준비, 출고, 점포 입고까지 진행상태가 이어집니다.
- 점포가 입고를 확인하면 해당 점포 재고가 자동으로 증가합니다.
- 품목별 안전재고를 기준으로 보충이 필요한 품목을 자동 표시합니다.

## 5분 추천 체험 순서

1. **본사 관리자**로 전국 지도와 조치 필요 점포를 확인합니다.
2. 점포 지도에서 점포명·지역·점주를 검색하고 상태 필터를 사용합니다.
3. **점포 생성**에서 점포명, 시·군·구, 도로명 주소와 점주를 등록합니다.
4. 계정 관리에서 점주 또는 점포 직원 계정을 생성합니다.
5. **지점장**으로 전환해 자기 점포 직원을 생성하고 물품을 요청합니다.
6. 본사에서 요청을 승인·준비·출고한 뒤 점포에서 수령·입고합니다.
7. 직원 역할의 출퇴근 화면에서 GPS 또는 체험용 출근을 실행합니다.

## 역할별 기능

### 본사 관리자
- 전체 점포 통합 현황
- 전국 점포 지도·검색·상태 필터
- 주소 및 GPS 좌표를 포함한 점포 생성
- 점주·직원 계정 생성, 점포 배정 및 사용 중지
- 점포별 재고 비교
- 안전재고 부족 현황
- 수발주 승인·반려
- 준비 및 출고 처리

### 지점장
- 담당 점포 재고 확인
- 필요한 물품 요청
- 출고된 물품의 수령·입고 확인
- 안전재고 부족 품목 확인
- 자기 점포 직원 계정 생성 및 관리
- 자기 점포 근태 현황 확인

### 점포 직원
- 담당 점포 재고 조회
- 등록 점포 반경 50m 이내 GPS 출근 및 퇴근
- 정식 운영판에서는 권한에 따라 폐기와 재고조정도 분리 가능

## GPS 출퇴근 원칙
- 점포의 도로명 주소와 좌표를 함께 등록합니다.
- 로그인 시 측정 위치가 등록 좌표 반경 50m 이내이면 출근으로 기록합니다.
- 위치 권한 거부, 반경 초과 또는 GPS 오차가 큰 경우 출근을 인정하지 않습니다.
- 브라우저 종료와 자동 로그아웃은 퇴근으로 처리하지 않습니다.
- 체험판의 **체험용 출근**은 실제 위치와 관계없이 18m 이내 샘플 기록을 만듭니다.

## 체험 데이터 안내
- 체험판은 SQL 및 Supabase를 사용하지 않습니다.
- 입력한 내용은 현재 브라우저에만 임시 저장됩니다.
- 다른 사람이나 다른 기기와 데이터가 공유되지 않습니다.
- **초기화** 버튼으로 언제든 처음 상태로 되돌릴 수 있습니다.
- SAN WMS의 실제 상품·재고·거래·사용자 데이터에는 영향을 주지 않습니다.

## 정식 운영판에서 추가 가능한 기능
- 실시간 알림 및 로그인 팝업
- 공급업체·매입단가 관리
- 폐기·손실·재고조정 승인
- 유통기한 및 제조 LOT 관리
- 점포별 사용량과 월간 비용 분석
- 모바일 푸시 또는 메신저 알림
