# 효소숲 Store Hub 체험판 사용설명서

## 무엇을 체험할 수 있나요?

효소숲 Store Hub는 본사와 여러 점포의 재고 및 수발주를 하나로 연결하는 매장관리 시스템입니다.

- 본사는 모든 점포의 재고와 부족 품목을 한 화면에서 확인합니다.
- 지점장은 배정된 점포의 재고를 관리하고 필요한 물품을 본사에 요청합니다.
- 점포 직원은 입고와 사용을 바로 기록합니다.
- 요청은 본사 승인, 준비, 출고, 점포 입고까지 진행상태가 이어집니다.
- 점포가 입고를 확인하면 해당 점포 재고가 자동으로 증가합니다.
- 품목별 안전재고를 기준으로 보충이 필요한 품목을 자동 표시합니다.

## 3분 추천 체험 순서

1. 상단 역할을 **본사 관리자**로 선택하고 전체 점포 현황을 확인합니다.
2. **지점장**으로 전환하고 담당 점포를 선택합니다.
3. **물품 요청**을 눌러 품목, 수량, 필요일과 사유를 입력합니다.
4. 다시 **본사 관리자**로 전환합니다.
5. 수발주 관리에서 방금 만든 요청을 승인하고 준비 및 출고 처리합니다.
6. 다시 해당 점포의 **지점장**으로 전환해 수령·입고 확인을 누릅니다.
7. 점포별 재고에서 요청 수량만큼 재고가 증가했는지 확인합니다.

## 역할별 기능

### 본사 관리자
- 전체 점포 통합 현황
- 점포별 재고 비교
- 안전재고 부족 현황
- 수발주 승인·반려
- 준비 및 출고 처리

### 지점장
- 담당 점포 재고 확인
- 필요한 물품 요청
- 출고된 물품의 수령·입고 확인
- 안전재고 부족 품목 확인

### 점포 직원
- 담당 점포 재고 조회
- 입고 및 사용 수량 등록
- 정식 운영판에서는 권한에 따라 폐기와 재고조정도 분리 가능

## 체험 데이터 안내
- 체험판은 SQL 및 Supabase를 사용하지 않습니다.
- 입력한 내용은 현재 브라우저에만 임시 저장됩니다.
- 다른 사람이나 다른 기기와 데이터가 공유되지 않습니다.
- **초기화** 버튼으로 언제든 처음 상태로 되돌릴 수 있습니다.
- SAN WMS의 실제 상품·재고·거래·사용자 데이터에는 영향을 주지 않습니다.

## 정식 운영판에서 추가 가능한 기능
- 사용자별 담당 점포와 권한
- 실시간 알림 및 로그인 팝업
- 공급업체·매입단가 관리
- 폐기·손실·재고조정 승인
- 유통기한 및 제조 LOT 관리
- 점포별 사용량과 월간 비용 분석
- 모바일 푸시 또는 메신저 알림
